# Engineering Application Suite: Fluid Flow & Heat Transfer

## Overview
This is a multi-module Streamlit application built for my Capstone Challenge. It integrates computational thinking, Object-Oriented Programming (OOP), and data analysis to solve core engineering problems.

## Modules Included
* **Module A: Pipe Flow Analyser:** Calculates velocity, Reynolds number, friction factor, and pressure drop for various fluids.
* **Module B: Heat Transfer Calculator:** Solves steady-state conduction through a flat wall and models transient cooling with real-time interactive plots.
* **Module C: Data Dashboard:** An interactive dashboard for uploading, filtering, and visualizing rock and fluid property datasets.
